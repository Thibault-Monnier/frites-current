# Getting Started

If you are new to FTC, check out [workflow.md](workflow.md).

Coding style guidelines are defined in [guidelines.md](style-guidelines.md).

You will find documentation about the codebase in [codebase.md](codebase.md). This is a great way to
understand the core architecture.

You should also take a quick look at [coordinate-systems.md](coordinate-systems.md). However, this
document is more technical and you must _not_ learn everything by heart.
